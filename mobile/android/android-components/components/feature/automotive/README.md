# [Android Components](../../../README.md) > Feature > Automotive

A component that holds logic related to Android Automotive OS, such as listening for Parked
or Drive state.

Note that Android Automotive OS is different from Android Auto. AAOS is an operating system
for the car's head unit hardware, whereas Android Auto is just a mirroring interface that
streams a phone's UI to the car's screen.

### Setting up the dependency

Use Gradle to download the library from [maven.mozilla.org](https://maven.mozilla.org/) ([Setup repository](../../../README.md#maven-repository)):

```Groovy
implementation "org.mozilla.components:feature-automotive:{latest-version}"
```
